# 🇮🇩 IPTV Public Indonesia

Kumpulan tautan IPTV dan referensi Electronic Program Guide (EPG) untuk penggunaan pada aplikasi IPTV yang kompatibel.

## 📺 Playlist IPTV

Playlist tersedia dalam format M3U dan berisi 83 channel.

**M3U URL:**
```text
https://raw.githubusercontent.com/arifstia/iptv-public/main/playlist.m3u
```

### Cara menggunakan
1. Salin URL playlist M3U.
2. Buka aplikasi IPTV yang mendukung URL M3U.
3. Pilih opsi tambah playlist melalui URL.
4. Tempel URL dan muat playlist.

## 📅 Electronic Program Guide (EPG)

EPG digunakan untuk menampilkan informasi jadwal program televisi.

**Sumber XMLTV Indonesia:**
```text
https://raw.githubusercontent.com/AqFad2811/epg/main/indonesia.xml
```

**Referensi EPG repository:**
```text
https://raw.githubusercontent.com/arifstia/iptv-public/main/epg.xml
```

Catatan: `epg.xml` di repository ini merupakan dokumen referensi sumber EPG, bukan file jadwal XMLTV yang dapat langsung digunakan sebagai EPG.

## 📡 Format yang tersedia

| File | Keterangan |
|---|---|
| `playlist.m3u` | Playlist IPTV |
| `epg.xml` | Referensi sumber EPG |
| `README.md` | Dokumentasi repository |

## ⚙️ Kompatibilitas

Playlist dapat digunakan pada aplikasi IPTV yang mendukung format M3U.

Dukungan EPG bergantung pada aplikasi dan kecocokan ID channel (`tvg-id`).

## 🔄 Pembaruan

Playlist dan dokumentasi diperbarui melalui repository GitHub ini.

Ketersediaan channel dan jadwal program dapat berubah sewaktu-waktu.
